Introduction to JavaScript

What is JavaScript?

JavaScript is a lightweight, interpreted, multi-paradigm programming language that is one of the core technologies of the World Wide Web, alongside HTML and CSS.

"Any application that can be written in JavaScript, will eventually be written in JavaScript." – Atwood's Law

Created by Brendan Eich at Netscape in just 10 days in 1995, JavaScript has grown from a simple browser scripting language into a full-stack powerhouse used for web, mobile, desktop, server, and even AI applications.

Where Does JavaScript Run?

  • Browser: Every modern browser has a built-in JavaScript engine (Chrome → V8, Firefox → SpiderMonkey).
  • Server (Node.js): JavaScript runs outside the browser via Node.js, enabling full-stack development.
  • Mobile: Frameworks like React Native let you build native mobile apps in JavaScript.
Dynamic Typing: JavaScript is dynamically typed — you don't declare variable types. The type is determined at runtime and can change.

Variables & Data Types

Declaring Variables

JavaScript has three ways to declare variables:

Keyword Scope Reassignable Hoisted
var Function ✅ Yes ✅ Yes (undefined)
let Block ✅ Yes ⚠️ TDZ
const Block ❌ No ⚠️ TDZ

Primitive Data Types

The 7 Primitives

  • String – Text: "Hello"
  • Number – Integers & decimals: 42, 3.14
  • Boolean – true / false
  • undefined – Declared but not assigned
  • null – Intentional empty value
  • Symbol – Unique identifier (ES6)
  • BigInt – Very large integers (ES2020)

Reference Types

Object, Array, Function

Stored by reference in memory. Changing one reference affects all references to the same object.

let arr = [1, 2, 3];
let obj = { name: "JS" };
let fn = () => "hello";

Functions & Scope

Ways to Define a Function

javascript
// 1. Function Declaration (hoisted)
function greet(name) {
    return `Hello, ${name}!`;
}

// 2. Function Expression
const greet = function(name) {
    return `Hello, ${name}!`;
};

// 3. Arrow Function (ES6)
const greet = (name) => `Hello, ${name}!`;

// 4. IIFE – Immediately Invoked Function Expression
(function() {
    console.log("Runs immediately!");
})();

Scope & Closures

A closure is a function that remembers the variables from its outer scope even after the outer function has returned.

javascript
function makeCounter() {
    let count = 0;
    return function() {
        count++;
        return count;
    };
}

const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
Hoisting: Function declarations are fully hoisted (callable before defined). var is hoisted but initialized as undefined. let and const are in the Temporal Dead Zone (TDZ) until their declaration.

DOM Manipulation

What is the DOM?

The Document Object Model (DOM) is a programming interface for HTML documents. It represents the page as a tree of objects that JavaScript can read and modify.

Selecting Elements

// Single element
document.getElementById("id")
document.querySelector(".class")

// Multiple elements
document.querySelectorAll("p")
document.getElementsByClassName("x")

Modifying Elements

const el = document.querySelector("h1");

el.textContent = "New Text";
el.innerHTML = "<span>Bold</span>";
el.style.color = "gold";
el.classList.add("active");

Event Listeners

javascript
const btn = document.getElementById("myBtn");

btn.addEventListener("click", function(event) {
    console.log("Button clicked!", event.target);
});

// Arrow function shorthand
btn.addEventListener("mouseover", (e) => {
    e.target.style.background = "gold";
});

Modern JavaScript (ES6+)

Key ES6+ Features

Destructuring & Spread

// Destructuring
const { name, age } = person;
const [first, ...rest] = array;

// Spread operator
const merged = [...arr1, ...arr2];
const clone = { ...obj1, ...obj2 };

Promises & Async/Await

// Async/Await
async function fetchData() {
    try {
        const res = await fetch(url);
        const data = await res.json();
        return data;
    } catch (err) {
        console.error(err);
    }
}
Template Literals: Use backticks (`) for multi-line strings and embedded expressions: `Hello, ${name}! You are ${age} years old.`

Array Methods

javascript
const numbers = [1, 2, 3, 4, 5];

// map – transform each element
const doubled = numbers.map(n => n * 2);      // [2,4,6,8,10]

// filter – keep matching elements
const evens = numbers.filter(n => n % 2 === 0); // [2,4]

// reduce – accumulate a value
const sum = numbers.reduce((acc, n) => acc + n, 0); // 15

// find – first match
const found = numbers.find(n => n > 3);       // 4
