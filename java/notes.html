Introduction to Java

What is Java?

Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible.

“Write Once, Run Anywhere (WORA)” – The Java Philosophy

Created by James Gosling at Sun Microsystems in 1995, Java has become one of the most popular languages for enterprise-scale applications, Android apps, and big data processing.

The Java Ecosystem

To run Java, you need to understand three core components:

  • JDK (Java Development Kit): The full toolset for developing Java apps.
  • JRE (Java Runtime Environment): The minimum environment needed to run Java apps.
  • JVM (Java Virtual Machine): The engine that actually executes the bytecode.
Platform Independence: Java code is compiled into bytecode, which can run on any device equipped with a JVM, regardless of the underlying hardware.

Key Characteristics

Feature Meaning
Simple Removes complex features like pointers and multiple inheritance (for classes).
Object-Oriented Everything is centered around "Objects" and "Classes".
Secure Runs in a "sandbox" environment to prevent unauthorized access to system resources.
Robust Strong memory management and exception handling to prevent crashes.
Multithreaded Can perform multiple tasks simultaneously within a single program.
Architecture Neutral Bytecode is not dependent on specific machine architecture.

Execution Model

How Java Code Runs

  • Source code (.java) is written.
  • The Java Compiler (javac) converts it to Bytecode (.class).
  • The JVM interprets or Just-In-Time (JIT) compiles the bytecode into machine code.
JIT Compilation: The JIT compiler improves performance by compiling bytecode into native machine code at runtime for frequently executed paths.

Structure of a Java Program

Every Java program must have at least one class and a main method.

java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

Data Types & Variables

Primitive Types

byte, short, int, long, float, double, boolean, char

Predefined by the language and named by a keyword. They hold actual values.

int count = 100;
double price = 19.99;
boolean isJavaFun = true;

Non-Primitive Types

String, Array, Class, Interface

Created by the programmer (except String). They reference objects in memory.

String name = "CodeStart";
int[] numbers = {1, 2, 3};

Control Flow & Loops

Conditional Logic

Java uses standard if-else blocks and switch statements for decision making.

java
int score = 85;

if (score >= 90) {
    System.out.println("Grade: A");
} else if (score >= 80) {
    System.out.println("Grade: B");
} else {
    System.out.println("Keep studying!");
}
Type Safety: Java is statically typed, meaning you must declare the variable type before using it, and it cannot change later.

Looping

For Loop

Standard loop for fixed iterations.

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

Enhanced For Loop

Easiest way to iterate through arrays.

for (int num : numbers) {
    System.out.println(num);
}
